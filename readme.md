# Developer Portfolio — HTML & CSS Practice Project

A static **Developer Portfolio Website** built using only **HTML5 and CSS3**.
This project was created as a practice task to strengthen my understanding of HTML structure, CSS styling, layout, positioning, Flexbox, background images, spacing, and reusable CSS classes.

## 🌐 Live Demo

🔗 **Live Website:**
https://infapk02.github.io/B-12-PORTFOLIO-PRACTICE-TASK/

---

## 📌 Project Overview

This is a personal developer portfolio website inspired by a professional portfolio design.

The website contains different sections to present a developer's:

- Introduction
- About information
- Technical skills
- Education
- Work experience
- Social links
- Contact form

The entire website was developed using **HTML and CSS only**, without JavaScript or any CSS framework.

## 📂 Website Sections

### 1. Navigation Bar

The navigation bar contains:

- Portfolio logo/name

- Blog link
- Hire Me button

### 2. Hero / Banner Section

The banner section introduces the developer with:

- Greeting
- Developer name
- Short introduction
- Download CV button
- Contact button
- Profile image
- Decorative background images

### 3. About Me

The About section contains:

- Short personal introduction
- Name
- Email
- Date of Birth
- Location

### 4. What I Do

This section displays the main technical skills:

- Vanilla JavaScript
- React
- MongoDB
- Node.js

Each skill is presented inside an individual card with an icon, title, and description.

### 5. Resume Summary

The resume section is divided into two parts:

#### Education

- Master's degree information
- University information
- Academic timeline

#### Experience

- Senior Front End Developer
- Junior Front End Developer
- HTML Developer

### 6. Contact / Footer Section

The footer contains:

- Let's Connect section
- Social media icons
- Contact information
- Contact form
- Name input
- Email input
- Message textarea

## 🚀 How to Run Locally

1. Clone the repository:

```bash

```

2. Navigate to the project directory:

```bash
cd B-12-PORTFOLIO-PRACTICE-TASK
```

3. Open `index.html` in your browser.

That's it! No additional dependencies or installation are required.
